# 首页文章列表分页计划

## 目标

实现首页文章列表的分页功能，每页显示 6 篇文章。

## 实现方案

采用 Astro 内置的 `paginate()` 函数实现服务端分页。

## 文件变更

| 操作 | 文件                        |
| ---- | --------------------------- |
| 删除 | `src/pages/index.astro`     |
| 新建 | `src/pages/[...page].astro` |

## URL 结构

| 页面    | URL  |
| ------- | ---- |
| 首页    | `/`  |
| 第 2 页 | `/2` |
| 第 3 页 | `/3` |
