# 如何高效做笔记

我使用 Obsidian 做笔记已经两年了。从最开始的随手记录，到现在的个人知识管理体系，这篇文章分享我的方法和心得。

## 为什么要用 Obsidian

市面上的笔记软件很多，我选择 Obsidian 的原因是：

1. **本地存储** —— 数据在自己手里，不用担心服务挂掉
2. **双向链接** —— 可以建立知识之间的联系
3. **完全免费**（基础功能） —— 不用花钱
4. **Markdown** —— 纯文本，方便迁移
5. **插件生态** —— 强大的扩展能力

## 基础设置

### 安装和同步

1. 从官网下载 Obsidian
2. 注册 GitHub 账号
3. 用 Git 做双向同步（电脑和手机都能用）

我的同步策略是：
- 电脑端：写笔记的主力
- 手机端：碎片时间看和改
- GitHub：数据备份

### 基础配置

Settings -> Editor 里推荐调整：

```markdown
- Default view for new tabs: Preview
- Show line number: On
- Fold indent: On
- Use tabs: Off
```

### 快捷键

我常用的快捷键：

| 快捷键 | 功能 |
|--------|------|
| Ctrl+P | 快速打开文件 |
| Ctrl+Shift+F | 全局搜索 |
| Ctrl+[[ | 跳转到链接 |
| Ctrl+] | 返回上一个位置 |
| Ctrl+Shift+K | 插入链接 |

## 笔记分类体系

我的文件夹结构：

```
├── 00_Inbox/          # 收集箱，新内容先放这里
├── 01_Work/           # 工作相关
│   ├── Project/       # 项目笔记
│   └── Learning/      # 工作中学到的东西
├── 02_Study/          # 学习笔记
│   ├── Programming/   # 编程
│   ├── System/        # 系统设计
│   └── Tools/        # 工具
├── 03_Life/          # 生活笔记
│   ├── Reading/      # 读书笔记
│   ├── Journal/     # 日记
│   └── Ideas/       # 想法
├── 04_Archive/       # 归档
└── _templates/       # 模板
```

### 命名规则

- 用英文或拼音，避免中文编码问题
- 用日期命名日志：`2024-01-15.md`
- 用主题命名知识笔记：`javascript-async.md`

## 双向链接和关系图谱

### 双向链接

Obsidian 最强大的功能是双向链接：

```markdown
# 写笔记时插入链接
[[相关笔记]]

# 效果：点击可以跳转到该笔记
# 之后在目标笔记可以看到" backlinks"
```

我的用法：
- 概念之间互相链接
- 项目笔记链接到相关文档
- 日记链接当天学到的知识

### 关系图谱

Obsidian 的关系图谱可以可视化知识之间的关系：

- 查看全局：左下角关系图谱按钮
- 筛选：可以用标签、文件夹筛选
- 搜索：通过关键词找相关笔记

## 使用技巧

### 1. 快速记录

QuickAdd 是快速记录的利器：

- 设置快捷键
- 配置模板
- 几秒钟创建一篇新笔记

我的设置：
- Ctrl+Shift+N：创建日记
- Ctrl+Shift+T：创建临时笔记
- Ctrl+Shift+W：创建周报

### 2. 每日回顾

每天早上/晚上，我用 10 分钟回顾：

1. 打开 Daily Notes
2. 看看昨天的待办
3. 记录今天学到的东西
4. 设置今天的待办

### 3. 周/月总结

周末我会做周总结：

```markdown
## 本周总结

### 完成的任务
- [x]

### 学到的东西
-

### 存在的问题
-

### 下周计划
- [ ]
```

### 4. 知识关联

每次写新笔记，我会：

1. 想想和哪些已有笔记相关
2. 加上链接
3. 如果没有，搜索一下再补充

### 5. 定期整理

每个月我会花 1 小时：

1. 查看最近未整理的笔记
2. 归档不再需要的
3. 合并相似的笔记
4. 补充缺失的链接

## 进阶：建立知识体系

### Zettelkasten 方法

这是一种卡片盒学习方法：

1. **原子化** —— 每条笔记只记一个想法
2. **唯一ID** —— 每篇笔记有唯一标识
3. **链接** —— 笔记之间互相链接
4. **索引** —— 建立主题索引

我的实践：
- 编程概念：每条笔记一个概念
- 概念之间用 `[[链接]]` 关联
- 用 MOC (Map of Content) 做主题索引

### MOC (Map of Content)

MOC 是主题索引：

```markdown
# JavaScript MOC

## 基础
- [[js-variables]]
- [[js-data-types]]

## 进阶
- [[js-async]]
- [[js-closure]]

## 框架
- [[react-basics]]
- [[vue-3]]

## 资源
- [[js-books]]
- [[js-tutorials]]
```

## 常见问题

### Q: Obsidian 难学吗？

A: 上手很简单，但要建立完整的知识体系需要时间。建议先从简单开始，慢慢优化。

### Q: 数据安全吗？

A: Obsidian 本地存储，建议用 Git 备份。我的流程：每次写完自动 commit。

### Q: 笔记太多找不到怎么办？

A:
1. 用 Ctrl+P 快速搜索
2. 用标签分类
3. 用文件夹整理
4. 用 MOC 建立索引

### Q: 应该先整理还是先记录？

A: 我的建议是**先记录，后整理**。来不及可以先放到收集箱，之后再分类。

## 我的工作流

1. **收集**：有任何想法、知识点，用 QuickAdd 快速记到收集箱
2. **整理**：每天/每周整理收集箱，归档到对应位置
3. **连接**：写新笔记时，思考和已有笔记的关系，加链接
4. **回顾**：定期回顾旧笔记，补充新的理解
5. **输出**：用自己的话写出来，是最好的学习方式

## 总结

使用 Obsidian 两年，我最大的收获是：

1. **知识变得可积累** —— 不再是看过就忘
2. **思维变得清晰** —— 写作是最好的思考方式
3. **效率提升** —— 找资料不用再全网搜
4. **形成自己的体系** —— 真正内化为自己的能力

如果你也想开始用 Obsidian，我的建议是：
- 先安装试用，不要一开始就想完美
- 从简单的笔记开始，逐步建立体系
- 坚持记录，形成习惯
- 享受这个过程
